## 🔍 Cómo Verificar el SEO

### Herramientas Recomendadas:
1. **Google Search Console** - Monitoreo de indexación
2. **Google PageSpeed Insights** - Performance
3. **Lighthouse** (Chrome DevTools) - Auditoría completa
4. **Screaming Frog** - Crawling técnico
5. **Ahrefs / SEMrush** - Análisis competitivo
6. **Schema Markup Validator** - Validar structured data
7. **Mobile-Friendly Test** - Google Mobile Test

### Comandos Útiles:
```bash
# Ver el sitio en producción
site:iafacorp.com

# Ver indexación en Google
site:iafacorp.com intitle:"IAFA"

# Verificar robots.txt
https://iafacorp.com/robots.txt

# Verificar sitemap
https://iafacorp.com/sitemap.xml
```
